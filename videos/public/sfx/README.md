# Sonidos de En Claro

Todos los `.wav` de esta carpeta los genera `scripts/sfx.py` con síntesis propia (numpy). No usan grabaciones
ni muestras de terceros, así que no tienen restricciones de licencia: se pueden usar en avisos comerciales.

| Archivo | Para qué |
|---|---|
| `slam.wav` | persiana que cae de golpe (gancho): chapa + kick + ruido grave |
| `metal.wav` | persiana que baja con rebote |
| `rattle.wav` | persiana que sube (traqueteo) |
| `thump.wav` | golpe de bajo (kick 150→40 Hz) |
| `whoosh.wav` | entrada de número o tarjeta |
| `tic.wav` | contador rodando |
| `click.wav` | kiosquito que se apaga |
| `glitch.wav` | pérdida en rojo |
| `riser.wav` | antes de una revelación |
| `lock.wav` | mira que se fija (doble bip) |
| `heart.wav` | latido doble |
| `buzz.wav` | tubo fluorescente que parpadea |
| `coins.wav` | plata que aparece |
| `caja.wav` | caja registradora |
| `spray.wav` | aerosol |
| `ascensor.wav` | podio que sube |
| `ding.wav` | llega el ascensor (el podio frena) |
| `ukelele.wav` | música irónica de "vida de rico" (rasgueo C–Am–F–G) |
| `boveda.wav` | puerta de bóveda que se abre (golpe grave + chirrido) |
| `viento.wav` | viento en la bóveda vacía |
| `papel.wav` | papelitos que caen |

Para reemplazar alguno por un archivo con licencia comercial, dejalo con el mismo nombre y anotá acá su origen.
